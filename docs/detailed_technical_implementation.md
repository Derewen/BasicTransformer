# Transformer Arithmetic: Detailed Technical Implementation

This document provides a detailed technical breakdown of the mathematics, shapes, and systems constraints of our ~1.2M parameter Flax/JAX Transformer, referencing the exact files and lines of implementation.

---

## 1. Vocabulary & Tokenization

Our model operates on a custom character-level vocabulary of **14 tokens** mapped at [main.py:L11-L24](../main.py#L11-L24).

| Character | Token ID | Role |
| :--- | :--- | :--- |
| `<pad>` | `0` | Align sequence lengths to 16 in memory |
| `0` to `9` | `1` to `10` | Represent numerical digits |
| `+` | `11` | Addition operator symbol |
| `=` | `12` | Answer separator symbol |
| `<eos>` | `13` | Stop-signal for autoregressive generation |

### Memory Slicing for Teacher Forcing
During training, the raw input sequence is generated, encoded, and sliced into $X$ and $Y$ batches inside the data pipeline at [main.py:L49-L69](../main.py#L49-L69):
* **`x_batch`:** `array[:, :-1]`, Shape `[B, 15]` (Sliced at [main.py:L66](../main.py#L66))
* **`y_batch`:** `array[:, 1:]`, Shape `[B, 15]` (Sliced at [main.py:L67](../main.py#L67))

## 2. Embedding Layer Details

Implemented in [embedding_layer.py:L5-L25](../embedding_layer.py#L5-L25).

1. **Token Embeddings (`token_embed`):**
   * Configured at [embedding_layer.py:L16](../embedding_layer.py#L16).
   * Weight matrix: $W_E \in \mathbb{R}^{14 \times 128}$.
2. **Positional Embeddings (`positional_embed`):**
   * Configured at [embedding_layer.py:L19-L22](../embedding_layer.py#L19-L22).
   * Weight matrix: $W_P \in \mathbb{R}^{16 \times 128}$.
   * Looks up position indices `0` to `15` generated by `jnp.arange(seq_len)`.
3. **Broadcasting Sum:**
   * Handled at [embedding_layer.py:L25](../embedding_layer.py#L25):
     $$\text{Embedding Output} = \text{Lookup}(x, W_E) + \text{Lookup}(\text{jnp.arange}(L), W_P)$$
   * Output Shape: `[batch_size, 15, 128]`.

## 3. Causal Multi-Head Self-Attention (MHA)

Implemented in [attention.py:L6-L45](../attention.py#L6-L45).

1. **Linear Projections:**
   * Initialized and applied at [attention.py:L16-L19](../attention.py#L16-L19).
   * Queries, Keys, and Values: $Q, K, V \in \mathbb{R}^{B \times L \times 128}$.
2. **Split Heads:**
   * Executed at [attention.py:L21-L24](../attention.py#L21-L24).
   * Reshape: `[B, L, 128]` $\rightarrow$ `[B, L, 4, 32]`.
   * Transpose axes: `[B, L, 4, 32]` $\rightarrow$ `[B, 4, L, 32]`.
3. **Scaled Dot-Product:**
   * Computed at [attention.py:L27](../attention.py#L27).
   * $\text{Scores} = \frac{Q K^T}{\sqrt{d_k}} \rightarrow$ Matrix multiplies $Q$ by $K$ transposed (transposing axes 2 and 3 using `transpose(0, 1, 3, 2)`).
   * Scores Shape: `[batch_size, 4, 15, 15]`.
4. **Causal Masking:**
   * Handled at [attention.py:L29-L32](../attention.py#L29-L32).
   * We apply `jnp.tril` to create a lower triangular matrix, and use `jnp.where` to set the masked out-of-bounds scores to `-1e9` ($-\infty$).
5. **Softmax:**
   * Computed at [attention.py:L35](../attention.py#L35): `nn.softmax(scores, axis=-1)`.
6. **Apply to Values:**
   * Computed at [attention.py:L38](../attention.py#L38): `jnp.matmul(attention_weights, v)`.
7. **Recombination & Output Projection:**
   * Executed at [attention.py:L40-L43](../attention.py#L40-L43).
   * Transpose to `[B, L, 4, 32]`, reshape to `[B, L, 128]`, and project using `nn.Dense` (name="output").

## 4. Block Integration & MLP

Implemented in [transformer_block.py:L5-L34](../transformer_block.py#L5-L34).

1. **Pre-LN Attention Block:**
   * Applied at [transformer_block.py:L13-L17](../transformer_block.py#L13-L17).
   * Calls `LayerNorm`, passes output to `CausalSelfAttention`, and adds the result back to `x` (Residual Connection).
2. **Pre-LN MLP Block:**
   * Applied at [transformer_block.py:L19-L32](../transformer_block.py#L19-L32).
   * Calls `LayerNorm`, projects $128 \rightarrow 512$ (`nn.Dense`), applies `nn.gelu` activation, projects back $512 \rightarrow 128$ (`nn.Dense`), and adds result back to `x`.

## 5. Master Model & Output Head

Implemented in [model.py:L6-L30](../model.py#L6-L30).

1. **Depth Stack:**
   * Loop executed at [model.py:L20-L22](../model.py#L20-L22).
   * Passes coordinates sequentially through `TransformerBlock` exactly `num_layers` (6) times.
2. **Output Head:**
   * Applied at [model.py:L27-L30](../model.py#L27-L30).
   * Translates final normalized 128-dimensional coordinate state back to 14 vocabulary character logits using `nn.Dense(features=self.vocab_size)`.

## 6. Loss & Optimization

Implemented in [main.py:L71-L97](../main.py#L71-L97).

* **`loss_fn`:** Defined at [main.py:L72-L84](../main.py#L72-L84). Compares predicted logits with `y_batch` using `optax.softmax_cross_entropy_with_integer_labels`, masked by `(y_batch != PAD_ID)` to ignore padding.

* **`generate`:** Defined at [main.py:L100-L136](../main.py#L100-L136). Implements the autoregressive generation loop.

## 7. Execution Environment & GPU/CUDA Constraints

Because JAX does not natively support GPU/CUDA acceleration on Windows, the choice of execution environment is critical for training speed:

* **Windows (Native):** Executes in CPU-only mode. Training 30,000 steps takes approximately **1.5 hours**.
* **WSL2 (Ubuntu):** Executes in GPU-accelerated mode via the NVIDIA WSL driver (e.g. utilizing an RTX 4090). Training 30,000 steps takes less than **3 minutes**.

### Setup & Commands in WSL2

Ensure the WSL2 environment has the correct JAX package installed with CUDA support:
```bash
pip install -r requirements.txt
pip install -U "jax[cuda12]"
```

Run scripts using the `wsl` command prefix from a Windows shell, or directly inside the WSL2 terminal:

* **Training:**
  ```bash
  wsl python3 main.py
  ```
* **Batch Evaluation:**
  ```bash
  wsl python3 eval.py
  ```
* **Interactive Inference:**
  ```bash
  wsl python3 inference.py
  ```
